# Screen Capture & Blur Studio (Chrome 拡張機能)

画面の表示領域または指定した選択範囲をキャプチャし、Chrome の**サイドパネル**上で全体ぼかし・部分ぼかし・モザイク・色調補正・フレーム装飾を行える Manifest V3 拡張機能です。

## フォルダ構成

```text
chromeextention/screen-capture-editor/
├── manifest.json            # Manifest V3 定義ファイル
├── service-worker.js        # バックグラウンド処理（画面キャプチャ・右クリックメニュー・履歴保存）
├── content/
│   ├── crop-overlay.js      # ページ上でのドラッグ範囲選択オーバーレイ
│   └── privacy-redactor.js  # ページ上の不適切テキスト伏せ字(●●●)・画像ぼかし処理
├── sidepanel/
│   ├── sidepanel.html       # サイドパネルUI（プログレスバー・AI保護ボタン・丸ペン設定）
│   ├── sidepanel.css        # サイドパネルのスタイル
│   └── sidepanel.js         # Prompt API連携・丸ペン/範囲ぼかし・フィルター加工＆保存ロジック
└── icons/
    ├── icon-16.png
    ├── icon-48.png
    └── icon-128.png
```

## インストール方法（開発者モード）

1. Chrome で `chrome://extensions/` を開きます。
2. 右上の **「デベロッパー モード」** を ON にします。
3. 左上の **「パッケージ化されていない拡張機能を読み込む」** をクリックします。
4. `chromeextention/screen-capture-editor` フォルダを選択します。

## 主な機能・使い方

1. **サイドパネルを開く**
   - ツールバーの拡張機能アイコンをクリックするとサイドパネルが開きます。
   - または Web ページ上で右クリックし、**「この画面をキャプチャしてサイドパネルで編集」** を選択しても即座にキャプチャ＆編集を開始できます。
2. **画面キャプチャ**
   - **表示画面をキャプチャ**: 現在表示されているタブ全体をキャプチャします。
   - **範囲を選択してキャプチャ**: ページ上でドラッグした矩形範囲だけを切り抜いてキャプチャします。
   - **手元の画像を読み込む**: ローカルの画像ファイルを読み込んで加工することも可能です。
3. **AI 個人情報・不適切判定と自動保護 (Prompt API / `LanguageModel`)**
   - **「文字を伏せ字・画像をぼかし（AI判定）」ボタン**:
     - Chrome 組み込みの Prompt API (`LanguageModel`) とパターン検出を用いて、Webページ内およびキャプチャ画像内の個人情報（氏名、電話番号、メールアドレス、住所、カード番号、APIキー、顔写真・身分証など）や公開不適切な箇所を判定します。
     - 実行中は**プログレスバー**で進行状況（1/4 走査 → 2/4 Prompt API テキスト・画像判定 → 3/4 伏せ字 `●●●` ＆画像ぼかし適用・再キャプチャ → 4/4 マルチモーダル視覚領域ぼかし検査）をリアルタイム表示します。
     - **「ページ復元」ボタン**で、Webページ上の伏せ字と画像ぼかしをいつでも元の状態に戻せます。
4. **部分ぼかし・モザイク加工（丸ペン / 丸の範囲 / 四角の範囲）**
   - **丸ペン (ブラシ)**: ペンのように丸いブラシでなぞった箇所に「部分ぼかし」「モザイク」「塗りつぶし」「注目マーカー」を入れられます。「丸の大きさ (ペン太さ)」スライダーで丸のサイズを変更でき、キャンバス上に円形ガイドが表示されます。
   - **丸の範囲 / 四角の範囲**: ドラッグで円形または矩形の範囲を指定して加工できます。
4. **全体ぼかし・フィルター・フレーム変更**
   - **全体ぼかし (0〜30px)**（ワンクリックプリセット付き）
   - **全体モザイク**
   - **明るさ / コントラスト / 彩度 / モノクロ / セピア**
   - **背景フレーム余白・角丸・背景色**
5. **保存・出力**
   - **クリップボードにコピー**: 加工後の画像をそのまま貼り付けられます。
   - **PNG画像を保存**: 加工後の画像を PNG ファイルとしてダウンロードします。
   - **最近のキャプチャ履歴**: 直近 5 件のキャプチャをサイドパネル下部のサムネイルからいつでも切り替えられます。
